# Baseball Statistics Visualization

This project is a web-based interactive data visualization tool for exploring baseball player statistics. It allows users to visualize and compare player performance across various statistical categories using parallel coordinates plots.

## Features

- **Interactive Parallel Coordinates Plots:** Visualize player statistics for batting, pitching, and fielding.
- **Player Searching:** Search for and select specific players to compare their performance over the years.
- **Dynamic Statistical Views:** Switch between different statistical datasets (e.g., Batting, Pitching) to explore various aspects of player performance.
- **Detailed Player Information:** Click on a player's line in the plot to view their detailed information.
- **Responsive Design:** The application is designed to work on different screen sizes.
